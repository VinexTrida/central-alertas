Sobre o projeto

Este site foi criado como parte do projeto de extensão universitária da disciplina Projeto Comunitário de Extensão Universitária da UNIVALI.

Todos os dias, às 8h, uma automação no GitHub busca matérias publicadas em sites como G1 Tecnologia, Olhar Digital, Canaltech e CNN Brasil. Primeiro, essas notícias passam por um filtro de palavras-chave relacionadas à cibersegurança.

As matérias selecionadas são enviadas para um modelo de inteligência artificial executado pela Groq, que verifica se o conteúdo realmente é relevante e extrai as principais informações da notícia.

Depois, esses dados são armazenados no Firebase e utilizados para alimentar automaticamente o site que você está acessando.
